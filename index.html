05.Research & Technical Write-ups

MEMORY FORENSICS

Detecting Process Injection via Volatility pslist/psscan

How DKOM-based process hiding works and how comparing pslist and psscan outputs surfaces hidden processes that standard task managers cannot detect.

When a process hides via DKOM, it unlinks from PsActiveProcessHead — invisible to pslist. But psscan scans raw memory for EPROCESS structures regardless of list integrity. A discrepancy between the two is a strong indicator of process injection or rootkit activity.
NETWORK FORENSICS

Identifying C2 Beaconing Patterns in Wireshark PCAP

How to recognize regular beaconing intervals in captured traffic, differentiate C2 check-ins from legitimate HTTPS, and extract indicators from packet payloads.

C2 beaconing produces consistent inter-packet intervals — commonly 30, 60, or 300 seconds. Applying a Wireshark filter for repeated connections to a single external IP and calculating delta times reveals this pattern effectively.
ENDPOINT FORENSICS

USB Device Forensic Analysis Using Autopsy

A practical breakdown of forensically examining a USB drive — from imaging and hash verification through file system analysis, deleted file recovery, and timeline generation.

Examination begins with a write-blocked image acquired via FTK Imager, verified with SHA-256. In Autopsy, the FAT32 file system is analyzed for allocated and deleted files. Magic byte inspection catches renamed files attempting to disguise their true type.
